# ruster-main (unstable)
Main setup for Ruster Linux, an Void-based distro that belongs to the Altus Project.

I will upload files from my current system here and i will set all up until i make the ISO.

If you want to "try" Ruster Linux on your existing Void install, you can download the files that you want from here.

Most probably that the entire main / of Ruster will be here, so it will be confirmed that the installer will extract the tar.zst from the releases branch.

This is the unstable branch that isn't compressed into a .tar.zst so you'll have to git clone this and compress it into a tar.zst.
